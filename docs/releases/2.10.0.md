# osury 2.10.0

One theme: **the four targets are now held to the same standard.** Until this
release only the ReScript output was ever compiled in the test suite; the OCaml,
Rust and Effect TS goldens were compared byte for byte — which pins the output,
not its correctness. Compiling them found real bugs. They are fixed, and the
check that found them is now part of `npm test`.

## New

### `--exact-optional` — "key absent" is not "value is null"

A field that is neither in `required[]` nor non-null has **three** wire states:
value, `null`, absent. By default osury folds the last two together. For
decoding a response that rarely matters; for encoding a **PATCH body** it is the
whole point — *leave alone*, *clear*, *set* are three different instructions.

| Target | Type under the flag |
|--------|---------------------|
| ReScript | `option<@s.null Nullable.t<t>>` |
| OCaml | `t option option` (`Oj.tri_field`) |
| Rust | `Option<Option<T>>` + `de_double_option` (plain serde reads both as `None`) |
| Effect TS | `Schema.optionalKey(Schema.NullOr(t))` |

Off by default: it changes existing types. Only the "not required + nullable"
row of the grid moves; see the README for the full table.

### Recursive types in every target

| Target | Self-reference | Mutual recursion (A→B→A) |
|--------|----------------|--------------------------|
| ReScript | ✓ (was ✓) | ✓ `type rec a = … and b = …` (**was: did not compile**) |
| OCaml | ✓ (was ✓) | ✓ `type a = … and b = …` (**was: did not compile**) |
| Rust | ✓ `Box<T>` (**was: `recursive type has infinite size`**) | ✓ |
| Effect TS | ✓ `Schema.suspend` + explicit `X` / `XEncoded` (**was: crash on import**) | ✓ |

Rust boxes only what needs it: a reference inside `Vec`/`HashMap` is already on
the heap. Effect TS output passes `tsc --strict` with
`exactOptionalPropertyTypes`.

## Fixed

- **Field-level `discriminator` without `mapping` used the schema *name* as the
  wire tag.** `anyOf: [IssueLoop, IssueBrokenLink]` + `propertyName: kind` was
  tagged `"IssueLoop"` although the member pins `kind: const "loop_found"`. The
  `const` now wins (all targets). ⚠ If you worked around this by hand, the
  generated constructors change: `IssueLoop(…)` → `@as("loop_found") LoopFound(…)`.
- **OCaml:** two variant types sharing a constructor name decoded into the wrong
  type (`This expression has type (issue, string) result`). Constructed values
  now carry their type.
- **Effect TS:** a blank line crept in before every enum's type export — gone.
- **ReScript:** an enum value that is a keyword (`"open"`, `"private"`) printed as
  `#open`, a syntax error. It is now quoted: `#"open"`.
- **Warnings:** "@schema skipped (sury-ppx …)" is a ReScript limitation, yet the
  OCaml, Rust and Effect TS generators reported it too. It is now ReScript-only.
- **Sample data** (demo preview, `SampleData.*`) is now valid for its own schema:
  list-encoded enums (`["Draft"]`), externally tagged unions (`{"Shine": {…}}`),
  `multipleOf`, and a recursion cut that never writes `null` into a required
  non-nullable field.
- **An input with no schemas is an error**, not `✓ Generated 0 types` with exit
  code 0 — that is what passing the wrong file looks like. ⚠ Exit code changes
  from 0 to 1 for such inputs.

## Demo

[The playground](https://osury.coreofkeen.com/) had
been failing to build since the compiler suffix moved from `.res.mjs` to `.mjs`
— the last successful deploy was 0.29.0. It is rebuilt on the real generators:

- all four targets side by side (the hand-rolled TypeScript printer is gone —
  the demo calls exactly what the CLI calls);
- `--refinements` / `--exact-optional` toggles;
- warnings and structured errors (path + kind + hint) in the log pane;
- the sample is the synthetic kitchen-sink spec from the repo.

`demo.test.mjs` now fails `npm test` the moment the demo drifts from `src/` again.

## Internals

- `targets-parity.test.mjs`: kitchen-sink + a new `recursion.spec.json`, × 4 flag
  combinations, × OCaml / Rust / Effect TS — each must **compile with its own
  toolchain** and **decode the sample generated for every schema**. ReScript is
  held to the same contract in `rescript-compiles.test.mjs`.
- `IR.recursivePredicate`, `IR.declarationGroups` (Tarjan SCC, dependencies
  first; module order is untouched when there is no mutual recursion, so goldens
  of non-recursive specs do not move).
- Verified against two production specs: ReScript and Rust output is
  byte-identical to 2.9.0; OCaml differs only by the constructor annotations;
  Effect TS differs only in the one recursive type that used to be broken.
- DEVELOPMENT_RULES: Rule 20 (presence × nullability), Rule 21 (cycles, and why a
  golden proves nothing on its own).

284 tests, all green.

## Known gaps

- Rust and OCaml do not enforce `pattern` / string `format`s (no regex engine
  without a dependency); Effect TS enforces `uuid` only among formats. Each case
  is reported as a warning — never silently dropped.
- Rust: an inline enum/record left in field position falls back to
  `String` / `serde_json::Value`.
- Path-derived type names keep the parameter's spelling
  (`GetV1Widgets_widget_idParams`), which Rust lints as non-camel-case.
