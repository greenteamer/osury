My code generator's tests were green for months. Three of its four outputs had never been compiled.

osury turns one OpenAPI spec into ReScript, Effect TS, OCaml and Rust. Every target had a golden test, but only the ReScript output was ever compiled. Once each target had to build with its own compiler and decode real samples, the bugs showed up. Then I ran it against two production specs and found three more that no fixture had.

osury 2.11 is out: all four targets compile and decode on both specs, on stable Sury 11.

I wrote up what happened and what replaced the golden tests. Link in the first comment.

If you maintain a code generator with snapshot tests: compile your snapshots.
