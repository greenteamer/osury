# osury 2.12.0

A maintenance release: no change to the generated code.

## Effect 4.0 (stable)

- Effect TS output is now tested against the stable **effect 4.0.5** (was
  4.0.0-beta.78). The generated code needed no changes: it type-checks under
  `tsc --strict` and decodes every sample, on the fixtures and on both production
  specs.
- The tests now decode through the same copy of `effect` the generated module
  imports. Since 4.0 stable, a schema checked by a second copy of the library
  fails its filters (`Expected an integer` for `42`); a real app has one copy, so
  this was a test artifact, not a bug in the output.

288 tests, all green.
