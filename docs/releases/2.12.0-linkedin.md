Eight months ago I shared osury, a CLI that turns an OpenAPI spec into ReScript types with Sury schemas. Since then it has generated every API type of Nyle, a production ReScript app, and that work took it from an early prototype to 2.12.

What changed for ReScript users:
• Discriminated unions from discriminator.mapping or a _tag const, untagged ones when the arms differ by shape
• Request bodies, every 2xx response and path/query params become types
• allOf merged, inline enums lifted into named poly variants, recursive types via type rec
• Untyped fields as JSON.t without breaking @schema, JSON null handled everywhere
• --refinements: format, minLength, minimum… as Sury checks
• --exact-optional: a PATCH body can say leave / clear / set
• Errors point to the exact JSON path, with a hint
• Built on stable Sury 11

The same spec also compiles to Effect TS (on stable Effect 4), OCaml and Rust, with the same unions, endpoint types and null handling, each checked by its own compiler.

The full write-up and a browser playground are in the comments.

npm i -D osury
